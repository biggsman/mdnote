# 글담 편집기 (Vditor 기반)

이 폴더는 [Vditor](https://github.com/Vanessa219/vditor) 3.11.3 의 TypeScript 소스를 가져와
글담에 맞게 고쳐 쓰는 편집기 코드입니다. 원본 라이선스(MIT)는 `LICENSE` 에 있습니다.

- 원본: Vditor 3.11.3 (`node_modules/vditor/src`)
- 마크다운 엔진(Lute), 아이콘, 언어 파일, 코드 강조·수식 등 외부 에셋은
  아직 `node_modules/vditor/dist` 에서 `public/vditor` 로 복사해 씁니다.
